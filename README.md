# Levis Nganga — deep-sea portfolio

Static site (HTML, CSS, JS). No build step.

## Deploy on GitHub Pages
1. Put these files in the root of your portfolio repo (replace the old ones).
2. Commit and push.
3. Repo Settings > Pages > deploy from the `main` branch, root folder.

## Edit your content
- `js/data.js` — email, GitHub link, and every project (live URL, source URL, description, case study).
- `about.html` — bio, education and skills.
- `assets/images/levis.jpg` — your photo (swap the file, keep the name).

## Optional: real footage behind the creatures
Drop a looping, muted clip at `assets/video/deep-sea.mp4`. The home page plays it
automatically and the leviathan, anglerfish and jellyfish swim over it.
